# 📌 About Project

ElGenral Linux Installer is a simple and fast tool that helps you install and run Linux environments inside Termux on Android devices.

The project supports:

- ✅ Ubuntu Installation
- ✅ Linux CLI Mode
- ✅ GUI Support (XFCE)
- ✅ VNC Connection
- ✅ Beginner Friendly
- ✅ Fast Setup

# 🎨 GUI Mode (XFCE)

Install XFCE Desktop:

```bash
apt install xfce4 xfce4-goodies -y
```

Install VNC Server:

```bash
apt install tigervnc-standalone-server -y
```

Start GUI:

```bash
vncserver :1
```

Connect using:

```text
127.0.0.1:1
```
